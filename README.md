# Text-to-SQL-query Application with Google Gemini

An end-to-end Generative AI application that converts **natural language
questions into SQL queries** using Google Gemini Flash 3.6, executes those
queries on a SQLite database, and displays the results through an
interactive Streamlit interface.

## 🚀 Features

-   **Natural Language to SQL** --- Converts plain English questions
    into SQL queries using Google Gemini Flash 3.6.
-   **Automated SQL Execution** --- Executes the generated SQL queries
    against a SQLite database.
-   **Interactive Web Interface** --- Provides a simple user interface
    using Streamlit.
-   **Custom Prompting** --- Uses a custom system prompt to guide Gemini
    toward generating clean SQL without Markdown code fences or extra
    `sql` tags.
-   **SQLite Database** --- Includes a standalone `sql.py` script to
    create the database, table, and sample student records.
-   **Query-Based Data Retrieval** --- Allows users to retrieve database
    information without manually writing SQL.

## 🏗️ How It Works

The application follows this workflow:

``` text
User Input (Natural Language)
            │
            ▼
     Streamlit Web App
            │
            ▼
 Custom Prompt + Gemini Flash 3.6
            │
            ▼
    Generated SQL Query
            │
            ▼
    SQLite Database
            │
            ▼
     Query Execution
            │
            ▼
      Results Displayed
```

The user enters a question in natural language. Gemini Flash 3.6 converts the
question into an SQL query based on the database schema and custom
prompt. The generated query is then executed against the SQLite
database, and the retrieved records are displayed in the Streamlit
application.

## ⚙️ Setup & Installation

### Prerequisites

Make sure you have:

-   Python 3.9 or higher
-   Anaconda (optional)
-   A Google Gemini API key

### 1. Create the Project Directory

``` bash
mkdir text-to-sql-gemini
cd text-to-sql-gemini
```

### 2. Create a Virtual Environment

#### Using Conda

``` bash
conda create -p venv python=3.9 -y
conda activate venv/
```

#### Using Python `venv`

``` bash
python -m venv venv
```

**Windows:**

``` bash
venv\Scripts\activate
```

**macOS / Linux:**

``` bash
source venv/bin/activate
```

### 3. Install Dependencies

Create a `requirements.txt` file containing:

``` text
streamlit
google-generativeai
python-dotenv
```

Then install the dependencies:

``` bash
pip install -r requirements.txt
```

### 4. Configure the Gemini API Key

Create a `.env` file in the root directory:

``` env
GOOGLE_API_KEY=your_google_api_key_here
```

Replace `your_google_api_key_here` with your actual Gemini API key.

> **Security:** Do not commit your `.env` file or expose your API key
> publicly.

## 🗄️ Database Initialization

The project uses SQLite3 with a `STUDENT` table.

Run the following command to create the database and insert the sample
records:

``` bash
python sql.py
```

### Database Schema

  Column      Data Type       Description
  ----------- --------------- -------------------------------
  `NAME`      `VARCHAR(25)`   Student's full name
  `CLASS`     `VARCHAR(25)`   Course / department
  `SECTION`   `VARCHAR(25)`   Section / group
  `MARKS`     `INT`           Marks obtained by the student

### Sample Data

The initial database contains sample records for students from the
**Data Science** and **DEVOPS** classes.

## 💻 Code Overview

### `sql.py`

The `sql.py` script:

1.  Connects to the SQLite database.
2.  Creates the `STUDENT` table if it does not already exist.
3.  Inserts sample student records.
4.  Prints the inserted records.
5.  Commits the changes and closes the database connection.

### `app.py`

The Streamlit application:

1.  Loads environment variables.
2.  Configures the Gemini API using `GOOGLE_API_KEY`.
3.  Sends the user's question and custom prompt to Gemini Flash 3.6.
4.  Receives the generated SQL query.
5.  Executes the query against `student.db`.
6.  Displays the returned records in the web interface.

## 🧠 Custom Prompt

Gemini is given information about the database schema:

``` text
STUDENT
├── NAME
├── CLASS
├── SECTION
└── MARKS
```

The prompt also provides examples of natural-language questions and
their corresponding SQL queries. It instructs the model to return the
SQL command without Markdown code fences or the word `sql`.

For example:

**Natural language:**

``` text
How many entries of records are present?
```

**Generated SQL:**

``` sql
SELECT COUNT(*) FROM STUDENT;
```

Another example:

**Natural language:**

``` text
Tell me all the students studying in Data Science class?
```

**Generated SQL:**

``` sql
SELECT * FROM STUDENT WHERE CLASS="Data Science";
```

## ▶️ Running the Application

After completing the setup and database initialization, start the

``` bash

```

The application will be available locally at:

``` text

```

Open the address in your browser to use the application.

## 🎯 Project Purpose

This project demonstrates how a Large Language Model can be connected to
a relational database to create a **Text-to-SQL application**.

Instead of manually writing SQL queries, users can ask questions in
natural language, allowing the LLM to translate those questions into
executable SQL and retrieve the corresponding database records.
